# API reference

Base URL: `http://localhost:8000`

Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

---

## Authentication

Admin endpoints require an `X-API-Key` header containing your `SUPABASE_SERVICE_ROLE_KEY`.

```
X-API-Key: <your-service-role-key>
```

In development, if neither `SUPABASE_SERVICE_ROLE_KEY` nor `RAZORPAY_KEY_SECRET` is set, all requests are allowed through (open dev mode).

## Campaigns

### GET /api/v1/campaigns

Returns all active campaigns with their current `amount_raised`. Used by the public pages.

**Authentication:** None

**Response — 200**

```json
[
  {
    "id": "uuid",
    "slug": "school-kits",
    "title": "Back to School 2026",
    "description": "...",
    "image_url": null,
    "goal_amount": 150000.0,
    "amount_raised": 42500.0,
    "start_date": "2026-01-01",
    "end_date": "2026-09-30",
    "status": "active",
    "created_at": "...",
    "updated_at": "..."
  }
]
```

---

### GET /api/v1/campaigns/all

Returns all campaigns regardless of status (`draft`, `active`, `archived`), ordered by creation date descending. Used by the admin dashboard Campaigns tab.

**Authentication:** None

**Response — 200:** Same shape as `GET /api/v1/campaigns` but includes all statuses.

```json
  "active_campaigns": 2

```

### GET /api/v1/campaigns/{slug}

Returns a single active campaign by its slug.

**Authentication:** None

**Path parameter**

| Parameter | Type | Description |
|---|---|---|
| `slug` | string | Campaign slug, e.g. `school-kits` |

**Response — 200:** Single campaign object

**Response — 404**

```json
{ "detail": "Active campaign with slug 'school-kits' not found" }
```

---

### POST /api/v1/campaigns

Creates a new campaign.

**Authentication:** `X-API-Key` required

**Request body**

```json
{
  "title": "Winter Blanket Drive 2026",
  "slug": "winter-blankets-2026",
  "description": "Distribute warm blankets to 500 families.",
  "goal_amount": 75000,
  "start_date": "2026-10-01",
  "end_date": "2026-12-31",
  "status": "active"
}
```

| Field | Type | Required | Constraints |
|---|---|---|---|
| `title` | string | Yes | 3–160 characters |
| `slug` | string | Yes | `^[a-z0-9]+(?:-[a-z0-9]+)*$`, unique |
| `description` | string | Yes | — |
| `goal_amount` | number | Yes | > 0 |
| `start_date` | date | No | Defaults to today |
| `end_date` | date | No | Must be ≥ `start_date` |
| `status` | string | No | `draft`, `active`, `archived`. Defaults to `active` |
| `image_url` | string | No | — |

**Response — 201:** The created campaign object

**Errors**

- `400` — slug already exists

---

### PUT /api/v1/campaigns/{campaign_id}

Partially updates a campaign. All fields are optional — only provided fields are changed.

**Authentication:** `X-API-Key` required

**Path parameter**

| Parameter | Type | Description |
|---|---|---|
| `campaign_id` | UUID | Campaign primary key |

**Request body**

```json
{
  "title": "Updated Title",
  "goal_amount": 100000,
  "status": "draft"
}
```

| Field | Type | Constraints |
|---|---|---|
| `title` | string | 3–160 characters |
| `description` | string | — |
| `image_url` | string | — |
| `goal_amount` | number | > 0 |
| `end_date` | date | — |
| `status` | string | `draft`, `active`, `archived` |

**Response — 200:** The updated campaign object

**Errors**

- `404` — campaign not found

---

### DELETE /api/v1/campaigns/{campaign_id}

Soft-deletes a campaign by setting its status to `archived`. The campaign and its donation records are preserved.

**Authentication:** `X-API-Key` required

**Response — 204:** No content

**Errors**

- `404` — campaign not found

## Donations

### GET /api/v1/donations

Returns all donation records, newest first. Each record includes `campaign_title` for display.

**Authentication:** None (admin dashboard use only)

**Response — 200**

```json
[
  {
    "id": "uuid",
    "campaign_id": "uuid",
    "campaign_title": "Back to School 2026",
    "donor_name": "Ramesh Kumar",
    "donor_email": "ramesh@example.com",
    "amount": 5000.0,
    "currency": "INR",
    "source": "offline",
    "status": "completed",
    "gateway_order_id": null,
    "created_at": "..."
  }
]
```

---

### POST /api/v1/donations

Initiates an online donation. Creates a pending donation record and returns a Razorpay order to open in the checkout modal.

**Authentication:** None

**Request body**

```json
{
  "campaign_slug": "school-kits",
  "donor_name": "Priya Sharma",
  "donor_email": "priya@example.com",
  "donor_phone": "9876543210",
  "amount": 1000,
  "currency": "INR"
}
```

| Field | Type | Required | Constraints |
|---|---|---|---|
| `campaign_slug` | string | Yes | Must match an active campaign |
| `donor_name` | string | Yes | 2–120 characters |
| `donor_email` | string | Yes | Valid email |
| `donor_phone` | string | No | — |
| `amount` | number | Yes | > 0 |
| `currency` | string | No | Only `INR` supported |

**Response — 201**

```json
{
  "donation_id": "uuid",
  "order_id": "order_abc123",
  "amount": 1000.0,
  "currency": "INR",
  "key_id": "rzp_test_..."
}
```

Use `order_id` and `key_id` to open the Razorpay checkout modal on the frontend.

**Errors**

- `404` — campaign not found or not active
- `500` — Razorpay order creation failed

---

### POST /api/v1/donations/offline

Records a completed offline (cash/cheque) donation directly.

**Authentication:** None (admin dashboard use only)

**Request body**

```json
{
  "donor_name": "Ramesh Kumar",
  "donor_email": "ramesh@example.com",
  "amount": 5000,
  "campaign_id": "uuid"
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `donor_name` | string | Yes | 2–120 characters |
| `donor_email` | string | Yes | Valid email |
| `amount` | number | Yes | > 0 |
| `campaign_id` | UUID | No | Defaults to first active campaign |

**Response — 201:** The created donation object with `status: "completed"`

**Errors**

- `404` — no active campaign found when `campaign_id` is omitted

---

### POST /api/v1/donations/verify

Verifies a Razorpay payment signature after the donor completes checkout, and marks the donation as `completed`.

For demo orders (`order_demo_*`), signature verification is skipped automatically so the full flow works on localhost without real Razorpay credentials.

**Authentication:** None

**Request body**

```json
{
  "razorpay_order_id": "order_abc123",
  "razorpay_payment_id": "pay_xyz789",
  "razorpay_signature": "<hmac-signature>"
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `razorpay_order_id` | string | Yes | Returned by `POST /api/v1/donations` |
| `razorpay_payment_id` | string | No | Provided by Razorpay after payment |
| `razorpay_signature` | string | No | HMAC-SHA256 of `order_id|payment_id` |

**Response — 200:** The updated donation object with `status: "completed"`

**Errors**

- `401` — signature verification failed
- `404` — no donation found for this order ID

---

### DELETE /api/v1/donations/{donation_id}

Permanently removes an erroneous donation record. Admin action only.

**Authentication:** `X-API-Key` required

**Response — 204:** No content

**Errors**

- `404` — donation not found

## Webhooks

### POST /api/v1/webhooks/razorpay

Receives payment event notifications from Razorpay directly to the FastAPI backend.

**Authentication:** HMAC-SHA256 signature in `x-razorpay-signature` header, verified against `RAZORPAY_WEBHOOK_SECRET`

**Handled events**

| Event | Action |
|---|---|
| `payment.captured` | Sets donation `status` to `completed`, stores `gateway_payment_id` |
| `order.paid` | Same as above |
| `payment.failed` | Sets donation `status` to `failed` |

When a donation transitions to `completed`, the database trigger `donations_issue_receipt` fires automatically and creates a row in the `receipts` table.

**Response — 200**

```json
{ "status": "received" }
```

**Errors**

- `401` — invalid or missing signature
- `400` — malformed JSON body

---

### POST /api/payments/razorpay/webhook

A second webhook handler, implemented as a Next.js Route Handler at `app/api/payments/razorpay/webhook/route.ts`. This handler updates donation status directly in Supabase (bypassing FastAPI) using the Supabase admin client.

Use this endpoint when the frontend is deployed independently without the FastAPI backend.

**Authentication:** HMAC-SHA256 signature in `x-razorpay-signature` header, verified against `RAZORPAY_WEBHOOK_SECRET`

**Handled events**

| Event | Action |
|---|---|
| `payment.captured` | Sets donation `status` to `completed` in Supabase |
| `payment.failed` | Sets donation `status` to `failed` in Supabase |

**Response — 204:** No content on success

**Errors**

- `401` — invalid signature
- `400` — malformed payload or missing donation reference
- `503` — Supabase not configured
